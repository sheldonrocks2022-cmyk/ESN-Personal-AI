Search the web with Jarvis.

Jarvis provides POST /api/search as an owner-only JSON API. Search requests run through Brave Search, or an optional self-hosted SearXNG instance. The service never follows result links or executes webpage instructions.

Private API access

The API requires an authenticated Jarvis dashboard session (with CSRF protection), or a separate ESN_SEARCH_API_TOKEN credential. A search-only key never provides access to account connections, bot credentials or customer servers.

Search queries are shared with the configured search backend. Do not include passwords, customer data or personal Discord messages.
